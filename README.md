# 🗂️ Image Slider 🏞️ ↔ 🌄 
Image Slider (JavaScript + HTML + CSS)

A simple, responsive image slider built with HTML, CSS, and vanilla JavaScript. It cycles through images using `querySelectorAll()`, `addEventListener()`, and `forEach()`.

✅ Key Features
-Smooth image slider behavior
-Next/Previous controls (or swipe-style buttons if you implemented them)
-Uses modern DOM selection and event handling:
        - document.querySelectorAll()
        - addEventListener()
        -  forEach()

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## ▶️ How to Run
Open `index.html` in your browser.
